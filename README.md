# Morlane

**Morlane is a Mac-native visual AI development environment for building, training, testing, and exporting local AI model projects.**

Morlane makes local AI development approachable through a clean visual workflow while keeping every project fully transparent and editable. Instead of hiding projects behind proprietary formats, Morlane stores everything as standard files and folders—including datasets, configuration, source code, training runs, checkpoints, and exports.

Everything runs locally on your Mac. No accounts, subscriptions, cloud training, or telemetry.

> **Status:** Public Beta (v1)

---

## Features

- Native macOS experience built with SwiftUI.
- Local-first architecture.
- Create and manage Tiny Language Model projects.
- Import text, Markdown, PDF, JSON, JSONL, and CSV datasets.
- Review, clean, and organize datasets before training.
- Configure models through a visual interface.
- Run local MLX training with live progress and logs.
- Test trained checkpoints in an integrated playground.
- Export complete, portable AI projects.
- Fully transparent and editable project structure.

---

## Current Beta

The current public beta focuses on **Tiny Language Models (Tiny LMs)**.

Support for additional AI project types—including vision models, audio models, reinforcement learning, and more—is planned for future releases.

---

## Requirements

- Apple Silicon Mac
- macOS 26 or later
- Python 3.9–3.13

## Privacy

Morlane is designed to be **local-first**.

Your datasets, projects, checkpoints, and exports remain on your device unless you explicitly move or share them.
