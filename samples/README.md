# Morlane Samples

These samples are intentionally tiny. They exist to demonstrate the v1 workflow and file formats, not model quality.

## Files

- `datasets/tiny-story-seeds.jsonl`: source JSONL records that Morlane can import.
- `tiny-lm-story-seeds`: a small Morlane project folder using the same records.

## Using The Sample Project

1. Build and run Morlane.
2. Choose Open Project.
3. Select `samples/tiny-lm-story-seeds`.
4. Review Data, Model, Train, Test, and Export.
5. Run Python runtime setup before training.

The sample project does not include checkpoints. Train it locally if you want to test the Playground.
